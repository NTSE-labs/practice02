# Практическая работа №2: обработка изображений

Проект содержит Jupyter Notebook с примерами базовой обработки изображений средствами Python и OpenCV. В работе используются четыре изображения из каталога `images`.

## Содержание работы

В [notebook.ipynb](notebook.ipynb) реализованы следующие этапы:

1. **Цветовые пространства**
   - загрузка изображений и преобразование BGR → RGB;
   - преобразование RGB → HSV → RGB;
   - визуализация каналов H, S и V;
   - оценка ошибки обратного преобразования.

2. **Выделение контуров**
   - перевод изображения в оттенки серого;
   - повышение локального контраста с помощью CLAHE;
   - сглаживание bilateral-фильтром;
   - выделение границ алгоритмом Canny;
   - морфологическое замыкание и фильтрация мелких контуров;
   - отображение найденных контуров и ограничивающих прямоугольников.

3. **Шумоподавление**
   - добавление гауссова и импульсного шума;
   - сравнение Gaussian blur, median blur, bilateral filter и Non-Local Means;
   - оценка качества по метрикам MAE и PSNR.

4. **Математическая морфология**
   - построение бинарной маски методом Оцу;
   - эрозия и дилатация;
   - открытие и замыкание;
   - построение морфологического градиента;
   - сравнение количества связных компонент до и после обработки.

5. **Преобразования изображений**
   - поворот, масштабирование и сдвиг;
   - изменение яркости и контраста;
   - размытие и повышение резкости изображения.

## Требования

- Python 3.12+;
- Jupyter Notebook;
- NumPy;
- Pandas;
- Matplotlib;
- OpenCV.

Установка необходимых пакетов:

```bash
python -m pip install jupyter numpy pandas matplotlib opencv-python
```

## Запуск

Из корневого каталога проекта выполните:

```bash
jupyter notebook notebook.ipynb
```

После открытия ноутбука последовательно выполните все ячейки командой **Run All** или тыкните по каждой ячейке. 
## Результат

Ноутбук формирует визуальные сравнения исходных и обработанных изображений, таблицы метрик шумоподавления и пояснения о практическом применении рассмотренных методов.
